# benastudio3d-nfc-contactos
Contactos digitales NFC de BenaStudio3D

## Supabase migration policy

No se deben crear migraciones nuevas ni ejecutar `supabase db push` desde este repositorio. Toda migración nueva de BenaStudio3D debe crearse, versionarse y aplicarse desde `C:\Users\Admin\benastudio3d-database`.

Las migraciones históricas existentes en NFC se conservan únicamente por compatibilidad y trazabilidad.
